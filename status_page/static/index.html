Animations 

          
Which animations each body gets from each installed library. A body needs the core
            of the
            Quaternius skeleton to play a library; a body missing some bones (fingers, toes...) plays it without those.
            Read-only:
            libraries are installed with python -m brain.appearance.models add-animations.
