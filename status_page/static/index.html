Looks 

        
Every look the companion has had, newest first. This page is read-only: tell the companion
          "go back to version N" and it restores that one (rebuilding it if the file is no longer kept). To make a look
          yourself, use the Build page.

        
The current look is an imported model, so the companion is keeping it:
          it will not redesign itself or take a request to change it. Tell it "you can change your look" to free it, or ask for a
          generated look.

Animations 

        
Which animations each body gets from each installed library. A body needs the core of the
          Quaternius skeleton to play a library; a body missing some bones (fingers, toes...) plays it without those. Read-only:
          libraries are installed with python -m brain.appearance.models add-animations.

        

        

      

    


    

      

        
Build your look 

        
Choose where to start, then change the body, clothes, colors and accessories. The viewer shows the
          body, its outfit and how it moves, live. Preview builds a picture of the whole look without changing anything;
          Apply makes it the companion's next look, a new version like any other. This is the one page that changes anything.
